AI Study Buddy — Mac 免费本地 AI 版本
==================================

你的 Mac 如果已经有 Ollama + qwen3.5:9b，不需要 OpenAI API Key。

步骤：
1. 保持 Ollama 程序开启（就是有羊驼图标、显示 qwen3.5:9b 的程序）。
2. Terminal 里执行 `ollama list`，检查是否安装 qwen3.5:9b。
   若提示 model 未安装，运行：ollama pull qwen3.5:9b
3. 双击或通过 Terminal 运行 RUN_MAC.command。
   如果解压在桌面上：bash ~/Desktop/AI_Study_Buddy_Ollama/RUN_MAC.command
4. 打开 http://localhost:8501。
5. 左侧选择 Local Ollama (FREE)，确认显示 Local Ollama detected。
6. 输入 TCP Three-Way Handshake，点击 Explain Topic。
7. 试试 Make it simpler，然后用 Generate Quiz 生成 3 道题并评分。

常见问题：
- Ollama not running：打开 Ollama 程序，再刷新网页。
- Model not found：执行 ollama pull qwen3.5:9b。
- 端口 8501 已被占用：关闭之前运行项目的终端（Control + C），再启动新版。
- Preview only 是预制示例，不算真正的 AI 演示。
- 本地 AI 免费，但会使用 Mac 的 CPU/GPU、内存和电量。

作业仍需：GitHub 仓库、课堂实时 demo、2 分钟以下演示视频；详见 README / PRESENTATION_GUIDE。
